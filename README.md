# AIDC Company Database

独立静态网站，230 条分类记录，207 个公司/业务名称。

保留 Company / Sector / Category / Note / Report。详情提供公司介绍、年度财务摘要及官方来源。财务摘要覆盖 10 个集团，关联多个业务条目；其余明确标记待补充。

部署：将 index.html 和 reports.json 放在 GitHub 仓库根目录，在 Settings → Pages 选择 main / root。index.html 内置数据，可直接离线打开。

日期：2026-11-17。技术来源优先 OCP、NVIDIA、Data Centre World；财务采用发行人公告及年报。
